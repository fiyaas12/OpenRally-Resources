# DUUFAAN Game Assets — v1.0

This is a base game-resource archive assembled from the current DUUFAAN `public/` asset directory. It preserves relative paths such as `models/`, `textures/`, `sounds/`, and `images/`. It is **not** an HD replacement pack and does not claim upscaled or higher-resolution content.

The asset list, byte sizes, and SHA-256 values are in `resource-pack-manifest.json`. The OpenRally project attribution and MIT license are included in `LICENSE`. User-supplied asset updates remain part of this archive.
